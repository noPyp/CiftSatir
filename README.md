# CiftSatir
İngilizce öğrenenler için ücretsiz çift altyazılı tarayıcı uzantısı. YouTube, Netflix ve desteklenen HTML5 video oynatıcılarda İngilizce ve Türkçe altyazıları aynı anda görüntüler. Anlamını ve telaffuzunu keşfetmek için herhangi bir İngilizce kelimeye tıklayın. Tamamlayıcı öğrenme web sitesiyle kelimeleri paylaşılan bir kitaplığa kaydedin.
